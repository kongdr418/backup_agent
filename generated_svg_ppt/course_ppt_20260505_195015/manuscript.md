## 什么是微信小程序

- **微信小程序**：无需下载安装，即用即走的轻量级应用
- 运行在微信客户端内，拥有独立的**渲染层**和**逻辑层**
- 优势：跨平台（iOS/Android）、流量红利、开发成本低
- 适用场景：低频工具、电商、内容展示、生活服务
- [icon: mobile] [icon: lightning]

---

## 开发环境搭建

- 注册微信小程序账号（[mp.weixin.qq.com](https://mp.weixin.qq.com)）
- 下载 **微信开发者工具**（官方 IDE，支持 Windows/Mac）
- 创建第一个项目：**AppID**（可使用测试号）、项目名称、目录
- [screenshot: 开发者工具界面截图]

---

## 项目结构与核心文件

- 全局配置：`app.json`（页面路径、窗口样式、tabBar）
- 页面结构：每个页面由 `.wxml`、`.wxss`、`.js`、`.json` 组成
- **数据绑定**：通过 `{{}}` 将 JS 数据渲染到 WXML
- [diagram: 项目文件树结构图]

---

## 开发流程演示

1. 创建小程序页面（在 `pages` 目录下新建文件夹和文件）
2. 编辑 WXML 搭建视图，使用 `wxss` 控制样式
3. 在 JS 中定义 `data` 和事件处理函数
4. 点击 **编译** 预览效果，使用 **真机调试** 测试 API
- [icon: mouse_click] [icon: bug]

## 常用组件与 API

- 组件：`<view>`（容器）、`<text>`（文本）、`<button>`（按钮）、`<image>`（图片）
- API：`wx.request()`（网络请求）、`wx.showToast()`（提示）、`wx.getUserProfile()`（用户信息）
- 注意：小程序 API 需 **鉴权**，部分接口需用户授权
