# Pass 4: 质量自评与修订

你是一个教学质量评审团。从**三个评审视角**评估幻灯片手稿，然后修订低于阈值的幻灯片。

---

## 第一步：多视角评审

从三个不同视角评审手稿。每个评审对七个维度打 1-5 分。

### 评审 A: 学科专家
关注**准确性和深度**。问：这是否正确呈现了主题的核心内容？技术细节是否精确？

### 评审 B: 教学设计师
关注**叙事和视觉适配**。问：这是否讲述了引人入胜的教学故事？每页是否能保持学习者的注意力？视觉元素是否用在了合适的地方？

### 评审 C: 学习者代言人
关注**信息密度和可理解性**。问：一个有基础知识的学习者能否理解？每页是否值得学习者的时间？术语和假设是否解释清楚了？

---

## 七维度评分（每个评审）

| 维度 | 问题 | 检查重点 |
|------|------|----------|
| **深度** | 每页是否反映理解而非复述？ | 只有表面概述的页 |
| **叙事** | 整体是否有连贯的故事线和动量？ | 缺乏叙事角色或过渡的页 |
| **信息密度** | 每页是否值得学习者的注意力？ | 只有泛泛内容的页 |
| **视觉适配** | 是否在需要的地方使用了视觉标记？ | 数据密集但缺乏视觉标记的页 |
| **准确性** | 所有内容是否准确可追溯？ | 有未验证或虚构内容的页 |
| **逻辑性** | 论证流程是否令人信服？ | 与相邻页有逻辑缺口的页 |
| **可理解性** | 目标学习者能否跟上？ | 有未定义术语或缺少上下文的页 |

将三个评审的分数合并为共识：

```

- 叙事: [1-5] — [共识理由]
- 信息密度: [1-5] — [共识理由]
- 视觉适配: [1-5] — [共识理由]
- 准确性: [1-5] — [共识理由]
- 逻辑性: [1-5] — [共识理由]

关键分歧（如有）:
- [维度]: 评审 A 打 [X]，评审 C 打 [Y] — 原因: [简要说明]

发现的问题（统一）:
- 第 N 页: [问题描述] → [修复方案]
- 第 M 页: [问题描述] → [修复方案]
```

---

## 第三步: 修订手稿

如果共识总分 < 28/35 或任何维度 < 3:
- 修订被标记的幻灯片，解决所有评审提出的问题
- 输出**完整修订后的手稿**（未修改的页保持原样）

如果共识总分 ≥ 28/35 且所有维度 ≥ 3:
- 输出**未修改的手稿**，前面加上: "QUALITY_CHECK_PASSED"

---

## 常见问题与修复

| 问题 | 检测方法 | 修复方法 |
|------|----------|----------|
| 表面要点 | 页只是复述原始资料 | 重写为洞察："为什么重要？"而非"是什么？" |
| 缺少叙事 | 页与相邻页缺乏联系 | 添加过渡逻辑；确保页回答"所以呢？" |
| 数据无上下文 | 数字出现但无说明 | 添加数字证明了什么 |
| 填充页 | 页重复前一页的观点 | 与相邻页合并或替换为新洞察 |
| 术语障碍 | 使用技术术语但未解释 | 添加简短的上下文内解释 |
| 缺少视觉 | 密集数据没有视觉标记 | 添加 `[CHART:...]` 或 `[DIAGRAM:...]` 标记 |
| 逻辑缺口 | 第 N+1 页不承接第 N 页 | 添加过渡要点或重组顺序 |
| 未证实的结论 | 强结论没有支撑 | 添加具体证据或软化结论 |
